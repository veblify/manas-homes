# 🏡 ManasHomes – Real Estate Platform by Vebify

ManasHomes is a modern real estate website designed and developed by **Vebify**, a digital agency focused on building scalable, user-friendly platforms.  
This project helps property buyers, sellers, and agents connect seamlessly with a clean interface, powerful search, and secure user management.

---

## ✨ Features

- 🔍 **Property Search & Filters** – Find homes by location, price, type, and amenities  
- 🖼️ **Image Galleries** – Showcase properties with high-quality visuals  
- 👤 **User Authentication** – Secure login and registration for buyers and sellers  
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile  
- ⚡ **Fast & Scalable** – Built with modern web technologies for performance and reliability  
- 🌐 **SEO Ready** – Structured for better visibility in local searches  

---

## 🛠️ Tech Stack

- **Frontend:** React, TailwindCSS, Vite  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Hosting:** Configurable (supports scalable cloud deployment)
